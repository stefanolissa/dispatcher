Create and send emails to your registered users in seconds.

== Description ==

Sending an email to your registered users should be easy.

With **Satollo Dispatcher** you can create an email in a matter of seconds, using the WordPress classic editor and immediately send it to all your users.

Of course, you can select the users by roles especially useful on membership sites.

No tricky configurations at all: only the sender email address and the sending speed. Both optional.

Compatible with any SMTP plugin.
